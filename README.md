# kinunuma-orienteering-2026-
城沼オリエンテーリング大会 特設サイト

## 順列と組合せ道場（junretsu/）

高校数学A「場合の数」の練習用Webアプリです。`junretsu/index.html` をブラウザで開くだけで使えます。

- **学ぶ**：和・積の法則、順列、円順列、重複順列、組合せ、同じものを含む順列・最短経路、組分け、重複組合せ（発展）の解説と、すべての並べ方を書き出す「書き出しラボ」
- **トレーニング**：単元ごとに数字を変えた問題が毎回作られます。ヒント・解説つき
- **演習問題**：基本演習10問・応用演習10問。採点して解説を確認できます
